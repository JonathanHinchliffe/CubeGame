# Cube Game
<hr>
Cube Game is a game where you must avoid hitting the grey cubes or the edge of the window for as long as possible.

Power ups spawn from time to time but not all power ups are good.

Blue power ups boost your score increase for a small time
Purple power ups allow you to eat grey cubes for a small time (they will come back eventually)
The pink power up changes your cube to pink (yes thats all)

<hr>
Scores are saved in game-results.csv
You can look at the save results in Data-Visualiser.ipynb. It even sorts by which game version the scores were made on
